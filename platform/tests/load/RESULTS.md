# Результаты нагрузочной проверки

Дата: 6 октября 2026 года.
Среда: локальный Minikube, один узел, Istio Gateway.
Генератор нагрузки: Locust 2.46.6, Windows, Python 3.13.12.
Доступ: kubectl port-forward → Istio Gateway → микросервисы.

## Базовый тест

3 виртуальных пользователя, длительность около 2 минут.
Сценарий: вход, создание комнаты, ожидание проекции,
создание и отмена бронирований, чтение ресурсов.

- Всего запросов: 172.
- Ошибок HTTP-запросов: 0.
- Успешных созданий бронирований: 61.
- Успешных отмен: 61.
- Средняя латентность: 35,2 мс.
- p95: 54 мс.
- Средняя скорость: 1,45 запроса/с.
- После теста LAG = 0 на всех шести партициях
  у групп audit-v1, bookings-v1 и notifications-v1.

При завершении Locust возникла ошибка фоновой записи CSV:
I/O operation on closed file.
Итоговая строка CSV проверена: 172 запроса, 0 ошибок.
Файл failures.csv содержит только заголовок.

## Отказ одного экземпляра bookings

Во время нагрузки включён тестовый отказ приложения
в одном из двух подов bookings через /tmp/campus-fault-until.
Health/readiness endpoints исключены из тестового отказа.

Тест завершён вручную через Ctrl+C примерно через 93 секунды.

- Всего запросов: 171.
- Ошибок: 4 (2,34%).
- POST create booking: 2 ответа 503.
- DELETE cancel booking: 2 ответа 503.
- GET list resources: без ошибок.
- p95 всех запросов: 51 мс.
- На Gateway, обслуживавшем нагрузку:
  ejections_enforced_total = 2;
  ejections_total = 2;
  upstream_rq_retry = 2;
  upstream_rq_retry_success = 2.
- На втором Gateway счётчики исключений равны 0.

Подтверждено исключение неисправного endpoint средствами
Istio Outlier Detection во время нагрузки Locust.
Повторные попытки GET успешны. Ошибки изменяющих операций
зафиксированы; полной прозрачности отказа для них нет.

После проверки маркер отказа удалён.
GET /api/bookings/ready вернул HTTP 200, scope=storage.

## Ограничения

- Нагрузка мала; предел производительности не определён.
- Port-forward направлял трафик на один под Gateway.
- Отказ приложения не моделирует отказ узла.
- Проверено Outlier Detection; переполнение лимитов
  connection pool отдельно не проверено.
- HTTP-трассы Istio доступны в Tempo/Grafana.
  Распространение trace context через Kafka не проверено.
