# Команда и распределение ответственности

В команде 2 участника. Проект содержит 6 бизнес-микросервисов,
по 3 сервиса на каждого участника.

| Участник | Сервисы | Ответственность |
|---|---|---|
| Эммануил | Users, Rooms, Equipment | Аутентификация и роли, каталоги аудиторий и оборудования, кэширование |
| Давид | Bookings, Notifications, Audit | Бронирование и конкурентный доступ, доставка уведомлений, аудит и архивирование |

Совместная ответственность:
- ТЗ, User Stories, Use Cases и NFR;
- C4 и Sequence Diagram;
- Kafka и контракты событий;
- Docker Compose, Nginx и GitHub Actions;
- интеграционные проверки и демонстрация.

Требование минимум одного микросервиса на участника выполнено.
Пожелание иметь по два микросервиса также выполнено.
Kafka, PostgreSQL, MongoDB, Valkey и Nginx считаются инфраструктурой,
а не дополнительными бизнес-микросервисами.
